# # Sistema de gestion de vacaciones 

El siguiente trabajo busca implementar un sistema de vacaciones que busque gestionar de forma rapida y sencilla las solicitudes de empleados.

# Descripcion

Este trabajo consiste en la implementacion de un sistema de gestion de vacaciones para un hospital.
La gestion anteriormente se hacia manualmente, con la utilizacion de papeleo y carpetas para guardar la informacion.

El objetivo de este sistema es digitalizar y simplificar el proceso, permitiendo el ahorro de materiales, una organizacion y mejor acceso a los datos y mejora en la atencion de solicitudes.

# Objetivos

Reducir el tiempo de proceso de solicitudes al pasarse al modo digital.
generar informes y estadisticas de las solicitudes

# Funcionalidades 

Registro de datos de empleados
poder consultar los datos solicitados
consulta de disponibilidad.
deteccion automatica de conflictos para su posterior resolucion
aprobacion o rechazo de solicitudes automaticamente en la mayoria de casos.
